# Paint (JavaScript) — Graficación por Computadora

[¡CLICK TO PLAY!](https://pacha2880.github.io/paint/)

Proyecto: una pequeña aplicación "Paint" nativa en JavaScript diseñada para pintar pixel por pixel.

Resumen
- Pintor simple que trabaja a nivel de píxel.
- Funciones incluidas: rellenado (fill), iluminación (simulación simple de iluminación), undo y redo.
- Herramientas para dibujar figuras geométricas (rectángulos, círculos, líneas) según los campos/valores del formulario.
- Interfaz mínima pensada para practicar técnicas de rasterizado y manipulación de canvas.
